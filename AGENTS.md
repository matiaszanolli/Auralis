# AGENTS.md

This project's agent/contributor brief lives in a single hand-maintained file:
**[CLAUDE.md](CLAUDE.md)**.

This stub exists only because some agent tooling (Codex and others) looks for
`AGENTS.md` specifically and doesn't read `CLAUDE.md`. Read `CLAUDE.md`
instead of duplicating its content here — an independently-edited second copy
of the same brief is exactly the shape the project's own "No variants"
principle (see `CLAUDE.md`'s Principles section) warns against, and is what
let this file drift out of date (version, toolchain flags, CI-gate section,
DB schema number) before it was collapsed into this pointer (#5027).
